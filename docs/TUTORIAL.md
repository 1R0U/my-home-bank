# 機能ごとの使い方案内（Issue #349・#452）

大人・子供とも、機能の画面を初めて開いたときに、その機能だけのチュートリアルを提示する。開始するかを選ぶ確認は画面中央のモーダル、「はじめる」を選んだ後の説明は画面下に場所を確保して表示する。対象ボタンから6pxの隙間を空けて、大人は青、子供は赤の枠で案内する。

操作を促す手順は対象の操作、説明だけの手順は「次へ」で進む。その機能の説明が終わったら案内を終了し、別の機能へ巡回しない。手順数も機能単位で表示する。

## 大人の初回案内

ホームの準備ができたら「ホームの見方 → ホーム右上の設定 → 家族の子供 → 名前で子供を追加する方法 → ログインコード発行と子供の端末でのログイン方法」の順で案内する。

初回案内は子供追加の説明までで終了する。プロフィール・通知等の設定全体の説明を続けない。終了した直後も設定の開始確認を割り込ませず、設定全体は次に設定画面を開いたときに案内する。子供をすでに追加している家庭でも方法を説明するが、追加やコード発行は必須にしない。

## 機能の単位

| ロール | 機能 |
| --- | --- |
| 大人 | ホームと子供追加、子供追加の見直し、タスク、ストア、経済、ローン管理、自動積立預金、履歴、所持金詳細、掲示板、町、自分の家、銀行、設定 |
| 子供 | 町、タスク、銀行、ストア、掲示板、履歴、自分の家、設定、自動積立預金 |

タスクのカテゴリ切替・作成フォーム・承認はタスク内、商品の一覧・管理・申請はストア内で案内する。経済・ローン管理・積立は各画面で独立して案内し、説明のためだけに他の画面を開かない。

積立の入口と見直し先は、大人が `/savings-adult`、子供が `/savings-child`。他方のロールの画面では案内しない。

履歴も大人が `/history-adult`、子供が `/history-child` を使い、他方のロールの画面では案内しない。

子供の最初の案内は町の移動・地図・メニューの説明だけとし、全ての建物を訪ねることを求めない。町と家は同じ3D画面内にあるため、家へ入ったときに家の案内へ切り替える。町・家ともシーンの準備ができるまで案内を出さない。

## 表示履歴と途中の移動

- ログイン中の利用者・ロール・機能ごとに、端末内のAsyncStorageへ `tutorial:v2:<role>:<userId>:<feature>` で表示履歴を保存する。DBの変更はない。
- 開始するか初回の開始確認を閉じると、その機能だけが表示済みになる。他の未案内の機能には影響しない。
- 大人の初回案内で子供のログイン方法まで進んだときは、子供追加の独立した案内も表示済みにする。設定全体は表示済みにしない。
- 旧形式 `tutorial:v1:<role>:<userId>` は一括案内を開始・閉じた記録で、各機能を見たことを判断できない。新形式には引き継がず、既存利用者にも各機能の初回訪問で新しい案内を提示する。
- 途中で別機能へ移ると元の案内を隠し、その画面の案内だけを表示する。同じ起動中は、元の説明対象の画面へ戻ると続きから再開する。
- 進捗は再起動をまたいで保持しない。利用者・ロールの切り替えやログアウトでは進捗を消し、前の人の文章や枠を表示しない。
- 保存に失敗しても操作を続けられる。エラーと再試行は現在表示中の機能だけを対象とし、他の機能へは表示しない。失敗した機能へ戻ると、その履歴を再試行できる。端末のデータ削除・別端末の利用では初回扱いになる。

## 見直し

設定の「使い方をもう一度見る」を開き、機能を選ぶと、その機能の入口で案内を開始する。自分の家を選んだ場合は町へ戻り、家へ入ると案内が始まることを選択肢にも表示する。

途中の「はじめから」は、その機能の案内だけをやり直す。大人の「ホームと子供の追加」ならホーム、それ以外はそれぞれの入口へ戻る。`lib/tutorialReturn.ts` の共通処理で既存の画面へ戻り、履歴がない場合は画面を置き換える。

## 確認

`tests/tutorialFeatures.test.mjs` で機能の境界・順番・ルート解決・保存キーを、`tests/tutorial.render.test.tsx` で初回案内・任意の順での訪問・機能別の保存・途中移動・町と家・見直し・利用者切り替え・保存失敗を確認する。`tests/tutorialReturn.render.test.tsx` は実際のExpo Routerで、やり直しや設定からの見直しで画面が重複しないことを確認する。

タスク・商品・承認待ち・子供アカウントが0件でも完了できる。保存・子供追加・コード発行・受注・報告・承認・購入・入出金・発行・融資・通知変更・ログアウトは必須にしない。通常の操作を行った場合は通常どおり実データに反映する。

実機では大人の初回案内、各機能の初回訪問、町と家の出入り、空の一覧、見直し、小さい画面でのスクロール、再起動後の非表示を確認する。
