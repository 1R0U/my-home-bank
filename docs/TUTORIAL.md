# はじめての使い方案内（Issue #349）

実際の画面を操作しながら進める。対象のボタンから6pxの隙間を空けて枠で囲み、画面下に説明を表示する。説明の場所を確保してから画面を描くため、操作するボタンや町の移動を覆わない。大人は青と白、子供は木と羊皮紙の表示に分け、子供の対象ボタンは赤い枠で強調する。

## 案内の順番

- 大人: タスクタブ → デイリー → タスク追加画面 → 閉じる → 承認 → ストア → 経済 → ホーム → 設定。
- 子供: 町のタスクの建物 → ウィークリー → デイリー → 町へ戻る → 銀行 → 町へ戻る → ストア → 町へ戻る → 掲示板 → 町へ戻る → 履歴 → 町へ戻る → 自分の家 → 町へ戻る → メニュー → 設定。

子供が建物へ向かう間は、ミニマップとメニューの間に行き先名と赤い矢印を表示する。歩くたびに現在位置から目的の扉の手前へ向くように更新し、3Dカメラの向き・見下ろす角度も反映する。目的の入口に着くとチェック印と「入る」（掲示板は「見る」）を表示する。読み込み・遷移中、地図・メニュー・会話・かざるモードでは矢印を隠す。

対象の操作をしたときだけ説明が進む。子供の建物への入場は、近づいて押す「入る」（掲示板は「見る」）、建物の直接タップ、全体マップからのワープで進む。掲示板・履歴は左上の戻るボタン、自分の家は玄関の「そとへ でる」で次の行き先へ進む。家の扉の名札を押して歩き出した場合は、実際に外へ出るまで進めない。タスク・商品・承認待ちが0件でも完了できる。作成の保存、タスクの受注・報告・承認、購入、銀行の入出金は案内完了の条件にしない。これらを通常どおり操作した場合は、通常どおり実データへ反映する。

## 初回表示と見直し

- ログイン中の利用者・ロールごとに、端末内の AsyncStorage に表示履歴を保存する。DBの変更はない。
- 初回はホームの準備ができてから開始の案内を提示する。子供は町のシーンの準備も待つ。
- 案内を始める、または初回の案内を閉じると表示済みになる。次の起動では自動表示しない。
- 設定の「使い方をもう一度見る」で、対応するホームから見直せる。途中でも「はじめから」でホームからやり直せる。
- 途中の進捗は再起動をまたいで保持しない。ログアウトや利用者・ロールの変更でも引き継がない。
- 保存の失敗は案内下部に表示し、再試行できる。端末のデータ削除・別端末の利用では初回扱いになる。

## 確認

`tests/tutorial.test.mjs` と `tests/tutorial.render.test.tsx` で順番、別操作・連打、初回表示、見直し、利用者の切り替え、保存失敗を確認する。

実機では大人・子供それぞれの一連の案内、町の直接タップと「入る」、空の一覧、途中で別画面へ進んだ後の「はじめから」、小さい画面でのスクロール、再起動後の非表示を確認する。
