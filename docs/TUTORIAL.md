# はじめての使い方案内（Issue #349）

大人・子供とも、開始するかを選ぶ案内は画面中央のモーダルに表示する。「はじめる」を選んだ後の説明だけ、画面下に場所を確保して表示する。開始前は下部パネルの領域を取らない。

実際の画面を操作しながら進める。対象のボタンから6pxの隙間を空けて枠で囲む。説明の場所を確保してから画面を描くため、開始後は操作するボタンや町の移動を覆わない。大人は青と白、子供は木と羊皮紙の表示に分け、子供の対象ボタンは赤い枠で強調する。

## 案内の順番

- 大人: タスク（デイリー・追加画面・承認・ウィークリー・限定・詳細）→ ストア（一覧・商品追加・子供の申請）→ 経済（金庫・追加発行・物価・ローン管理・自動積立・経済ログ）→ 履歴（期間切替・グラフ・取引）→ ホーム（残高・タスクへの入口）→ 所持金詳細（サンプルの預金・ローン表示）→ 掲示板 → 町（移動・地図・ワープ・銀行・キャラ・装飾・きがえ・自分の家）→ 設定（名前・プロフィール・子供追加とコード発行・通知・クレジット・見直し・ログアウト）。
- 子供: 町のタスクの建物 → ウィークリー → デイリー → 町へ戻る → 銀行 → 町へ戻る → ストア → 町へ戻る → 掲示板 → 町へ戻る → 履歴 → 町へ戻る → 自分の家 → 町へ戻る → メニュー → 設定。

子供が建物へ向かう間は、ミニマップとメニューの間に行き先名と赤い矢印を表示する。歩くたびに現在位置から目的の扉の手前へ向くように更新し、3Dカメラの向き・見下ろす角度も反映する。矢印の回転角は `lib/rpg-hub/tutorialArrow.ts` で計算する。目的の入口に着くとチェック印と「入る」（掲示板は「見る」）を表示する。読み込み・遷移中、地図・メニュー・会話・かざるモードでは矢印を隠す。

操作を促す手順は対象の操作で進む。大人の説明だけの手順は「次へ」で進み、別画面にいる間は「説明の画面へ戻る」を表示して進捗を保つ。経済からローン管理を開く説明ボタンは、データがないときも使える。積立の紹介後はローン管理・積立の画面を閉じて経済へ戻る。

子供の建物への入場は、近づいて押す「入る」（掲示板は「見る」）、建物の直接タップ、全体マップからのワープで進む。掲示板・履歴は左上の戻るボタン、自分の家は玄関の「そとへ でる」で次の行き先へ進む。家の扉の名札を押して歩き出した場合は、実際に外へ出るまで進めない。

タスク・商品・承認待ち・子供アカウントが0件でも完了できる。保存・タスクの受注や承認・購入・入出金・追加発行・融資・通知変更・ログアウトは案内完了の条件にしない。これらを通常どおり操作した場合は、通常どおり実データへ反映する。

## 初回表示と見直し

- ログイン中の利用者・ロールごとに、端末内の AsyncStorage に表示履歴を保存する。DBの変更はない。
- 初回はホームの準備ができてから、中央に開始確認を提示する。子供は町のシーンの準備も待つ。Androidの戻る操作でも閉じられる。
- 案内を始める、または初回の案内を閉じると表示済みになる。次の起動では自動表示しない。
- 設定の「使い方をもう一度見る」で、対応するホームから見直せる。途中でも「はじめから」でホームからやり直せる。
- やり直し・説明対象への復帰・設定からの見直しは `lib/tutorialReturn.ts` の共通の戻る処理を使い、履歴があるときは既存の画面まで戻る。ホームが履歴になければその画面へ置き換えて移動するため、町のWebViewや大人用タブを重複させない。
- 途中の進捗は再起動をまたいで保持しない。ログアウトや利用者・ロールの変更でも引き継がない。
- 保存の失敗は案内下部に表示し、再試行できる。端末のデータ削除・別端末の利用では初回扱いになる。

## 確認

`tests/tutorial.test.mjs` と `tests/tutorial.render.test.tsx` で順番、別操作・連打、中央の開始確認から下部説明への切り替え、説明だけの手順・画面復帰、初回表示、見直し、利用者の切り替え、保存失敗を確認する。大人の各画面の描画テストでは、実際の入口・タブ・戻るボタンで案内が進み、商品追加・融資承認・設定保存が必須にならないことを確認する。

`tests/tutorialReturn.render.test.tsx` は実際のExpo Routerを使い、建物・各画面・設定からのやり直しでホームが1つだけになることと、戻り先がない直接起動でも移動できることをルート状態で確認する。`tests/tutorial.render.test.tsx` では、案内と無関係な再描画でContextが変わらず、進捗変更で操作関数が作り直されないことも確認する。

実機では大人・子供それぞれの一連の案内、町の直接タップと「入る」、空の一覧、途中で別画面へ進んだ後の「はじめから」、小さい画面でのスクロール、再起動後の非表示を確認する。
